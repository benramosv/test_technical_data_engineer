# Runbook de operación

El candidato debe completar este runbook con pasos verificables para:

1. Diagnosticar una ejecución fallida.
2. Identificar si el problema está en fuente, transformación o calidad.
3. Reprocesar una fecha de forma segura.
4. Evitar duplicados después de un retry.
5. Validar freshness y volumen posteriores al reproceso.
6. Aplicar un rollback lógico o restaurar una versión Delta cuando corresponda.
